# CatWar: скрытие имени нападающего в логе БР

Юзерскрипт (Tampermonkey) для `catwar.su` / `catwar.net` — скрывает имя нападающего в логе боевого режима (БР).

## Что делает

Каждая запись лога боя выглядит так:

```
Златозейм => я (хвост)
```

Скрипт заменяет имя нападающего на `???`:

```
??? => я (хвост)
```

Работает вместе с юзерскриптом uwu (компактный лог `#uwu-Compacted-Fight-Log`) и без него (стандартный лог `#fightLog`).

## Установка

- Страница с кнопкой: https://cw-mod.github.io/br-hide-attackers/
- Прямая ссылка: https://cw-mod.github.io/br-hide-attackers/catwar-br-hide-attackers.user.js

1. Tampermonkey → создать скрипт → вставить содержимое `catwar-br-hide-attackers.user.js` → Ctrl+S,
   либо открыть прямую ссылку выше и согласиться на установку.
2. Открыть игровую `/cw3` — при загрузке и во время боя имена нападающих скрываются автоматически.

## Настройка

`REPLACEMENT` в начале скрипта — чем заменять имя: `'???'`, `'***'`, `'[скрыто]'`, `''` (пусто — имя просто исчезнет).

## Как устроено

- Стандартный лог: игра добавляет в `#fightLog` записи `<span class="log_paws|log_claws|log_teeth">Имя => я (часть)</span>`.
- Компактный лог uwu: текст записи лежит в `.text` внутри `.log_paws`.
- Скрипт следит за обоими контейнерами (MutationObserver), маскирует и существующие записи, и новые.
